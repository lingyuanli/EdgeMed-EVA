# 系统蓝图

## 1. 研究问题

核心问题不是“给 4B 模型堆更多工具”，而是：

> 在不使用 Med-CMR 测试答案、源文章或评测器反馈训练的前提下，能否让 4B 原生视觉语言模型产生可定位、可验证、真正影响最终答案的视觉证据，并以更低成本超过强开源基线？

将其拆成三个可证伪假设：

- **H1（垂域学习）**：证据结构化的医学训练比普通答案 SFT 更能提升 Med-CMR 的 Visual Accuracy、Consistency 和 Ground-Truth Match；
- **H2（Agent）**：在同一检查点上，受控的证据工具策略相对 tool-free 解码有正的净收益，而不是仅由额外 token 或训练漂移造成；
- **H3（可信度）**：证据指标和反事实依赖测试能发现仅看答案分数无法识别的“答对但证据错”和“工具调用但无贡献”。

## 2. 最小系统

```text
Med-CMR 样本
  └─ 输入规范化/面板与视图绑定
      └─ Qwen3.5-4B 生成初始证据需求
          ├─ 无需工具 ───────────────┐
          └─ 受预算约束的 crop/zoom ─┤
                                     v
                          证据表 + 竞争性假设
                                     v
                           一致性/引用静态检查
                                     v
                    MCQ 选项或开放题答案 + 证据
                                     v
             答案/证据/因果/工具/校准/成本评测
```

第一版只保留两个确定性工具：图像元数据/面板解析和多尺度 crop/zoom。跨视图与时间绑定先作为输入组织模块，不作为自由调用的“工具”。医学检索和专科分割/检测模型进入后续候选池，只有错误分析显示其预期收益超过复杂度和泄漏风险才启用。

## 3. 三层方法结构

### 3.1 表征层：Evidence Packet

每个可引用视觉证据使用统一结构：

```json
{
  "evidence_id": "E1",
  "image_id": "img_0",
  "view_or_time": "current_frontal",
  "region_xyxy_1000": [120, 210, 480, 620],
  "observation": "右下肺野局灶性密度增高",
  "supports": ["H1"],
  "contradicts": ["H2"],
  "acquisition": "native|crop",
  "confidence": 0.78
}
```

坐标使用 0–1000 归一化。没有合法定位时，模型必须显式写 `region_xyxy_1000: null`，不能虚构框。

### 3.2 推理层：假设竞争而非长 CoT

模型内部可以推理，但外部监督对象是短、可检查的结构：

1. 任务类型与证据需求；
2. 1–3 个竞争假设；
3. 每个假设的支持/反对证据；
4. 是否需要额外视觉操作；
5. 最终答案、证据引用和置信度。

这样避免把冗长自然语言链条等同于正确临床逻辑，也降低 4B 模型的生成负担。

### 3.3 控制层：选择性工具策略

调用工具需要同时满足：

- 当前关键证据不可辨认或多个假设因局部细节无法区分；
- 操作目标可被明确描述为图像、区域和预期判别信息；
- 未超过 2 轮、4 个 crop、总视觉 token 和延迟预算；
- 同一无效区域不重复调用。

工具输出只扩充证据，不能直接输出诊断。最终答案仍由同一 backbone 根据完整证据表产生。

## 4. 两种使用模式

- **Benchmark 模式**：按题目要求强制输出选项/答案；置信度仅用于评测，不允许弃答改变官方准确率分母。
- **Clinical-safe 模式**：允许 `insufficient_evidence`，单独报告 coverage-risk。该模式不能与官方强制回答分数混报。

## 5. 贡献成立条件

| 卖点 | 最低成立证据 | 强成立证据 |
|---|---|---|
| 4B 垂域模型 | 相同测试协议下显著超过未训练 Qwen3.5-4B 与普通答案 SFT | 超过强开源公开结果，且无维度灾难性回退 |
| 多模态 Agent | 同检查点 tool-enabled > tool-free，且 Call Gain > Call Harm | 删除被引用 ROI 比删除无关 ROI 的性能下降显著更大 |
| 证据评测 | 能区分答对证错、答错证对、工具有害 | 证据指标与专家复核一致，并预测错误/校准风险 |

商业模型超越只能作为最高目标，不能预先写入结论。若只在自行构建的开发集上超过商业模型，表述必须限定为该代理集。
