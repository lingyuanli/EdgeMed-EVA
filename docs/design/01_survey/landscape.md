# 方法景观与迁移判断

## 1. Benchmark 与失效模式

Med-CMR 包含 20,653 个问题，其中 16,655 个选择题、3,998 个开放题，覆盖 12 种影像模态和七类复杂推理维度。论文报告的主要瓶颈不是单一知识缺失，而是细粒度视觉识别、跨视图/时间/上下文整合和医学长尾。其开放题评分将 visual accuracy 与 ground-truth match 赋予更高权重。

设计含义：只做医学文本注入不够；优化目标必须直接覆盖视觉证据和证据整合。论文也观察到部分医学微调模型在复杂选择题上退化，因此必须监测通用多模态能力和各维度回退。

## 2. 医学专属 Agent

MMedAgent 使用一个动作规划/聚合 MLLM 调用 grounding、segmentation、classification、report generation、RAG 和 VQA 等工具。它证明“统一调度专科工具”可行，但公开评测规模较小，覆盖的任务和模态远少于 Med-CMR。

迁移判断：保留 action schema 和工具结果聚合思想；不在 MVP 复制六工具架构。为 12 种模态准备专科工具会扩大工程面、泄漏面和失败面，且难以证明每个工具的独立贡献。

## 3. Active perception 与工具 RL

DeepEyes 以 interleaved text/image 轨迹训练 crop-and-zoom 策略，并通过样本筛选保留“工具可能有用”的题。它支持受控视觉操作路线。

但后续 MED 分析表明，在 Qwen2.5-VL/Qwen3-VL 类模型上，crop/zoom RL 的总体提升可能主要来自 tool-free 的模型内在学习；工具训练的重要作用更像减少工具引入的伤害和 schema 干扰，而不是稳定纠正原本答错的样本。

迁移判断：工具调用率不是卖点证据。每个训练检查点必须同时运行 tool-free 与 tool-enabled；记录 Call Gain、Call Harm、工具质量和策略选择。训练奖励应惩罚不必要调用，不能直接奖励“多调用”。

## 4. Grounded generation

MAIRA-2 将报告拆成原子句并附可选 bounding boxes，使用当前/侧位/既往图像与文本上下文；RadFact 同时评估逻辑与空间 grounding。这提供了证据表和跨视图输入的成熟范式。

限制是 grounding 正确不等于临床结论正确：句级 evaluator 可能漏掉句内矛盾、部分错误和上下文捷径。因此本项目将区域引用、临床 observation、假设关系和最终答案分开评分。

## 5. 偏好与过程监督

MMedPO 构造“看似合理但视觉不一致”的负响应，并用临床相关性和视觉置信度加权偏好训练。ChestX-Reasoner 的结果支持“答案监督完成域对齐 + 过程奖励改善推理”的顺序，且显示纯 RL 或只用 reasoning SFT 可能不稳定。

迁移判断：先做答案+证据 SFT，再做 grounded preference；RL 必须排在可靠 baseline 和偏好训练之后。负例应覆盖错误答案/正确证据、正确答案/错误证据、病灶遗漏、跨视图冲突和不必要工具调用。

## 6. 小模型与基础设施

Qwen3.5-4B 官方模型卡给出原生多模态、长上下文和工具使用能力。它是合理的端侧主干，但“能运行”不等于“能在 24GB 上全参训练”。本设计默认 4-bit QLoRA、冻结视觉编码器，先验证 4090 单卡可行性。

V100 不支持原生 BF16，且软件栈兼容性和吞吐弱于 4090；因此只作为 FP16 兼容备选，不作为主训练平台。

## 7. 收敛后的研究空白

现有工作分别展示了复杂医学 benchmark、专科工具 Agent、视觉工具 RL、grounded report 和偏好优化，但缺少一个同时满足以下条件的公开闭环：

- 4B 级原生多模态 backbone；
- 面向多模态复杂临床推理，而非单一胸片任务；
- 同检查点反事实证明工具净收益；
- 答案、区域证据、证据逻辑、校准和成本共同评测；
- 训练数据与 benchmark 源材料严格隔离。

该空白足以支持设计，但是否形成论文贡献仍取决于真实实验。
