# Gap Map

## G0：必须先解决的可执行性空白

Med-CMR 公开仓库当前未展示完整数据下载与官方 evaluator。本项目在取得数据、许可和评分入口前不能宣称已经具备完整评测闭环。

交付：`data_access_receipt.json`、`evaluator_receipt.json`、20 题人工核对和固定版本哈希。

## G1：4B 模型的域对齐与视觉保持

未知点：Qwen3.5-4B 经过医学训练后，是获得真正视觉改善，还是只获得答案先验并损害通用视觉能力？

最小实验：B0/B1、答案 SFT、证据 SFT，冻结测试与通用保持集；七维度和视觉证据指标同时报告。

## G2：工具净收益的因果证明

未知点：Agent 增益是否来自工具调用、更多计算、提示结构或同一训练中的内在学习？

最小实验：同 checkpoint 四臂对照——direct、structured no-tool、tool-enabled、oracle crop；固定 token/采样；Call Gain/Harm 和 ROI 删除。

## G3：答案与证据的解耦评测

未知点：官方开放题 rubric 是否能可靠区分答对证错和答错证对？

最小实验：构造四象限挑战集；确定性 localization/引用检查 + 专家临床评审 + 冻结 LLM judge。

## G4：跨模态/跨视图泛化

未知点：从胸片类 grounded 数据得到的能力能否迁移到 CT、MRI、病理、眼底和内镜等模态？

最小实验：按 modality 留一、低资源切片和模态平衡采样；不允许总体均值掩盖单模态崩溃。

## G5：长尾知识与检索边界

未知点：检索能否补长尾知识而不把 benchmark 源文章或近重复病例泄漏到上下文？

最小实验：先做无检索主线；候选语料去重、来源审计和时间截断后，再作为独立 RAG 分支测试。

## 研究优先级

`G0 > G1 > G3 > G2 > G4 > G5`。如果 G0 不通过，工作只能停留在代理 benchmark；如果 G1 不通过，不应投入 RL；如果 G2 不通过，Agent 不能作为核心卖点。
