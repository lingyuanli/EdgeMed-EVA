# Skeptic Report：最强反对意见

## 1. “刷爆 baseline”可能只是数据泄漏

Med-CMR 题目由病例报告和源文章构造。如果训练/RAG 语料包含同一文章、同一图或近重复病例，4B 的高分没有研究价值。必须建立图像哈希/感知哈希、文本 n-gram/embedding 近重复和文献 DOI/PMID 隔离；所有训练数据保留 provenance。

## 2. 商业模型对比可能不公平

论文报告分数与本地重跑可能使用不同时间点、提示、图像预处理和 judge。主表必须区分：`paper-reported`、`official leaderboard`、`locally reproduced`。只有完全相同输入与评分协议的结果才能作直接显著性比较。

## 3. 证据输出可能只是装饰

模型可以先凭先验作答，再生成看似合理的框和解释。相关 ROI 删除、图像打乱和证据交换是核心因果测试；若答案不依赖所引用证据，“证据可信化”主张失败。

## 4. Agent 增益可能只是多算力

Agent 多轮读取图像和生成 token，本来就获得更高推理预算。必须有 compute-matched no-tool 对照；报告 wall time、visual tokens、generated tokens 和显存峰值。

## 5. 4B 可能没有足够容量覆盖 12 种模态

如果总体分数依靠高频模态，长尾模态仍然失败，卖点不成立。需报告宏平均、最差模态、七维度以及每个切片的置信区间。专科工具只能在 oracle study 显示明确上界后添加。

## 6. LLM judge 可能偏爱结构化长答案

Agent 输出更长、更规整，judge 可能给更高 coherence 分而非更正确。需用长度匹配、答案顺序交换、去格式化复评与人工双标量化偏差。

## 7. 训练成本可能被低估

4B QLoRA 本身便宜，但多图高分辨率、长轨迹生成、在线 RL rollout 和多次全量评测会主导成本。资源计划按阶段设硬预算；在单卡 smoke 和小规模收益门通过前不允许 4 卡长跑。

## 8. 临床可信度表述可能越界

Benchmark 提升不能推出临床安全、诊断有效性或可部署性。论文应表述为“在复杂医学多模态推理 benchmark 上的证据一致性改善”，并明确非临床用途。
