# 矛盾图

## K1：工具使用是否带来推理增益？

- 支持：DeepEyes、MMedAgent 报告工具增强后的任务提升。
- 反面：MED 将总变化拆为 intrinsic drift 与 tool-induced effect，发现提升可能主要来自工具外学习，工具本身仍制造伤害。
- 裁决设计：在同一 checkpoint、同一解码预算上成对运行工具开/关；计算 Call Gain/Harm；增加相关 ROI 删除和无关 ROI 删除。
- 禁止表述：只凭 agent 总分高于 base 就宣称“学会使用工具”。

## K2：医学微调是否必然改善医学推理？

- 支持：多项垂域工作显示专业任务提升。
- 反面：Med-CMR 报告部分医学微调模型在复杂 MCQ 上落后于通用多模态模型。
- 裁决设计：每一阶段同时报告总体、七维度、通用视觉保持集；任何关键维度下降超过预设容忍度都阻断下一阶段。

## K3：结构化证据是否等于可信？

- 支持：grounded generation 让引用可检查。
- 反面：MAIRA-2 指出句级评估漏掉内部矛盾、部分错误与上下文捷径；框也可能与最终诊断无关。
- 裁决设计：分开计算区域定位、observation 正确性、claim–evidence entailment、答案和反事实依赖。

## K4：外部 LLM judge 是否足以评开放题？

- 支持：Med-CMR 使用强模型按多维 rubric 评分，具有可扩展性。
- 反面：judge 版本、提示、位置和语言偏差会影响结果；同源模型可形成循环验证。
- 裁决设计：冻结 judge 版本/提示/温度；匿名化、交换答案顺序；350–700 题做专家双标；主结论同时给确定性指标和 judge 指标。

## K5：更多工具是否更强？

- 支持：专科工具可能补足 4B 模型容量。
- 反面：每个工具增加故障、延迟、模态缺口和训练/测试泄漏面。
- 裁决设计：工具进入系统前必须有错误切片、oracle upper bound、真实工具准确率和逐工具净收益四项证据。
